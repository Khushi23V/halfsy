Miama.woff2  (or .woff, or .otf - base.css lists all three)

Miama is SIL OFL, free for commercial use, and NOT on Google Fonts,
so it has to be self-hosted. Convert at https://transfonter.org.

Check the filename case matches exactly. A mismatch is a silent 404 -
the font simply never appears and nothing logs an error.

Note from the type scan: Miama renders small for its point size
because of its large ascenders and descenders. A 10pt optical size
needs to be set around 15-20pt to match the Urbanist beside it.
